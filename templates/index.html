Blockchain Verification

Every time a transaction is flagged as fraud by the AI classifier, an automated trigger initiates a smart contract call to the storeTransaction function. The details are recorded immutably on Ganache Ethereum network.

GuardChain AI Core System Architecture

Modular pipeline demonstrating end-to-end integration of Deep Learning classification and Blockchain auditing.

1. Transaction Intake

Client submits credit card transaction features (Amount, Time, PCA V1-V28).

2. Standardizing Scaler

Preprocessing normalizes features via fitted StandardScaler weights.

3. AI Classifier

Consensus pipeline evaluates transaction using PyTorch MLP or Random Forest.

4. Web3.py Solidity Call

If classified as fraud, automated script initiates Ganache Smart Contract call.

5. Immutable Ledger

Transaction hash generates block mined on Ethereum, ensuring permanent audit trail.
